# Personal Website

This is a personal website project for Emelda. The repository contains various assets, scripts, and configuration files for the website.

## Project Structure

- `index.html` - Main landing page of the website
- `config.php` - Configuration file for PHP scripts
- `get_api_key.php`, `save_conversation.php`, `test_db.php`, `m.php`, `t.php` - PHP backend scripts
- `db.mp4` - Media file (possibly a video)
- `dmlogo.png`, `lmlogo.png`, `emelda-avatar.png`, `sizzlin1.png`, `sizzlin2.png`, `starai1.png`, `starai2.png`, `TastyConnect.png` - Image assets
- `light2.MOV` - Video asset
- `emelda.txt` - Text file (purpose unspecified)

## Getting Started

1. Clone the repository to your local machine.
2. Ensure you have a web server with PHP support (e.g., XAMPP, WAMP, or a live server).
3. Place the project files in your web server's root directory.
4. Open `index.html` in your browser to view the website.

## Notes

- Some PHP scripts may require additional configuration or a database connection.
- Media and image files are used for website content and branding.
